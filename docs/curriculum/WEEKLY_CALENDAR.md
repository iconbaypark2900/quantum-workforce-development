# Weekly calendar — Quantum Readiness Month

Assume a Wednesday start so working professionals can use a weekend in the middle of each course. Shift as needed. All times are learner effort, not lecture length.

## Week 1 — Find your fit (QR-1)

| Day | Effort | Activity |
|-----|--------|----------|
| Wed | 45 min | Live orientation: eight pathways, what this month is not |
| Thu–Fri | 90–120 min | Complete `/learn/navigator`; screenshot pathway summary. Optional `/learn/readiness` quiz |
| Sat | 90 min | Draft learning plan (primary, stretch, artifact, non-goal) |
| Sun | 30 min | Optional office hours |
| Mon–Tue | 60 min | Peer read of plans; facilitator comments |

**Exit ticket:** plan signed (self + guide).

## Week 2 — Qubit fundamentals (QR-2, Qolour)

| Day | Effort | Activity |
|-----|--------|----------|
| Wed | 2–3 hr | Qolour workshop block (games + Qubi 1.1–1.4) or facilitated remote kit |
| Thu | 90 min | Qubi 1.5–1.6; “what entanglement is not” pair work |
| Sat | 2 hr | Gates/circuits/fidelity (3.1, 3.3, 3.4 + H, X, Z, CNOT) |
| Sun | 45 min | Write qubit card |
| Tue | 30 min | 10-item concept check (async) |

**Exit ticket:** qubit card + check ≥ 70% with no category mix-up on the four pillars.

## Week 3 — Business foundations (QR-3, IBM)

| Day | Effort | Activity |
|-----|--------|----------|
| Wed | 90 min | IBM lessons 1–2; journal one claim you will stop repeating |
| Thu–Fri | 2 hr | Lessons 3–5; note two applications in your SME |
| Sat | 60 min | Cohort seminar: good vs poor use cases |
| Sun | 90 min | Lesson 6 (quantum ready) + draft memo |
| Tue | 60–90 min | IBM Training exam (encouraged); submit memo |

**Exit ticket:** memo in; badge recorded if earned.

## Week 4 — Vocabulary + classical baseline (QR-4)

| Day | Effort | Activity |
|-----|--------|----------|
| Wed | 2 hr | Closed-book glossary drill; peer mark vagueness |
| Thu | 2 hr | Write the five baseline fields on the portfolio example (or own SME problem) |
| Fri–Sat | 3–4 hr | Map, run classical + hybrid/quantum-inspired path in Portfolio Lab, fill table |
| Sun | 90 min | Capstone brief |
| Tue | 45 min | Office hours: go / no-go critique |

**Exit ticket:** capstone brief. No baseline → no pass.

## Standing rituals

- **Office hours:** 25 minutes, twice weekly (guide).  
- **Language rule:** if a word is in the glossary, use the glossary meaning in discussion.  
- **Hype rule:** “advantage” requires a baseline sentence.
